Why is binary search so much faster than looking one by one?

Both searchers look for the same number in a sorted list. One walks from the start. The other opens the list in the middle and throws away the half that can’t contain the answer. Tap any square to choose what to find, then press Run.

Checks needed

Doubling the list adds only one more check for binary search, because each check halves what’s left. That’s the whole trick: arrange the data so one look rules out half of it.
