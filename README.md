# ecosystem-sims

Small interactive simulations of things that are hard to grasp from text alone. Each one is a single self-contained HTML page: open it in a browser, no install needed.

## Simulations

- **[Network collapse](network-collapse/index.html)**: a plant-pollinator network you can break. Remove species at random or hubs first, and see who goes extinct as a result and how the survivor curves differ.
- **[Binary search](binary-search/index.html)**: a sorted list searched two ways, scanning one by one and halving each time, with a slider showing how far the gap grows on huge lists.
- **[Language drift](language-drift/index.html)**: a town where everyone starts with the same word and sounds change as it is passed on. Compare dialects forming when people only talk to neighbours against a single form taking over when everyone mixes.

## Notes

The network model is deliberately simple: a species survives while it has at least one living partner. It illustrates redundancy and cascades rather than predicting any real ecosystem.
