How does one word turn into many?

Everyone in this town starts out saying the same word, patik. Each generation, every person picks up the word from someone they talk to, and now and then a sound changes. Each colour is a different pronunciation. Press Run and watch dialects form.

Different pronunciations over time

Try “Immediate neighbours” and run for a while: regions with their own version of the word appear and stay. Then try “Everyone in town”: new forms keep appearing, but they get copied and overwritten across the whole town, so no stable regions form.
